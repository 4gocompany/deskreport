# Diretrizes de Contribuição (Contributing)

O DeskReport é mantido e desenvolvido pelo time da **4Go Company**.

## 1. Relato de Bugs e Discussões
- Ficamos muito felizes em receber relatos de problemas, dúvidas e sugestões de melhoria!
- Por favor, utilize a aba **Issues** do GitHub para reportar bugs detalhados ou discutir ideias com a comunidade.

## 2. Política de Pull Requests
- Para preservar a consistência arquitetural, a governança multi-tenant e o rumo do produto, **não aceitamos Pull Requests externos de código**.
- Todas as implementações e decisões técnicas passam pelo ciclo interno de especificação, engenharia e auditoria da 4Go Company.
- Caso tenha uma sugestão de código ou feature, abra uma Issue descrevendo o caso de uso.
